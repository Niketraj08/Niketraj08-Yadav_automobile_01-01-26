## 📌 About the Project

**VIP Computer** is a modern, full-featured **hardware e-commerce platform** built for a real client offering custom PC builds, laptops, printers, CCTV systems, and repair services.

> ⚠️ **Note:** This repository showcases the **demo version** of the project. The **live client website** is significantly different in branding, content, and configuration — it has already been **handed over to the client**, who now manages everything independently through the built-in **Admin Panel**.

This repo is kept **public** for portfolio, learning, and reference purposes — feel free to explore, use, or build upon it. 🚀

---

## ✨ Key Highlights

- 🎨 **Sleek Dark-Themed UI** with a bold yellow/orange accent identity
- 🛒 **Full Product Catalog** with category filters, brand partners & smart search
- ⚖️ **Compare Hardware Tool** — side-by-side spec matrix for multiple products
- 📄 **Auto-Generated Spec Report (PDF)** — instantly downloadable comparison sheets
- 📊 **Market Intelligence Widget** — live price trend sparkline per product
- 📥 **Instant Sales Enquiry System** — direct WhatsApp + form-based lead capture
- 🔐 **Admin Panel** — client has full control over products, pricing, stock & content
- 📱 Fully **responsive** and optimized for a fast, modern shopping experience
